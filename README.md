# Отчёт по SMM · Академия АНИНОТ

Отчёт за октябрь 2026: статистика площадок с конверсиями, стратегия, воронки, готовый контент и контент-планы на 22.10–04.11.2026.

Страница — один файл `index.html` и папка `img/`. Работает на телефоне и компьютере.

## Как открыть по ссылке через GitHub Pages

1. Загрузите содержимое папки в репозиторий на GitHub.
2. В репозитории откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/ (root)`, нажмите Save.
4. Через 1–2 минуты страница откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
